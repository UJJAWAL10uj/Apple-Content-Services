# Data dictionary

| Field | Meaning |
|---|---|
| event_id | Stable event identifier |
| event_name | Festival or seasonal moment |
| event_date | Calendar date used for the event window |
| region | Geographic relevance; not a measured region split |
| search_terms | Semicolon-separated Google Trends query labels |
| date | Date/week from Trends export |
| keyword | Exact query label used in export |
| geo | Geography code, normally IN |
| interest | Normalized Trends interest index |
| snapshot_date | Date an Apple chart snapshot was collected |
| category | Apple App Store category feed |
| rank | Position in returned chart, 1 = top |
| app_id | Apple app identifier when parseable |
