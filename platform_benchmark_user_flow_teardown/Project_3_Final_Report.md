# Project 3 — Platform Benchmark & User-Flow Teardown

**Audit date:** 30 October 2026  
**Market:** India  
**Services in scope:** Zomato, Swiggy, Domino's, EatSure  
**Task:** Set location → discover restaurant → inspect menu item → add to cart → review fees → reach checkout without ordering.

## Executive summary

This package contains a structured, evidence-led benchmark framework and a public desk-research pass over official app-store listings and official web properties. Public storefront presence and official-site reachability were found for the four services across the sources listed in `Public Source Register` and the workbook's `Platform Audit` sheet.

This is **not yet a completed hands-on usability test**. No app was installed or operated as part of this desk-research pass. The following remain deliberately unscored and unfilled: install/launch success on a user's device, locality-specific availability, actual discovery and menu behaviour, cart fee breakdown, pre-order checkout progression, observed friction, and UX ratings.

## Scope and method

- Platforms: iOS App Store, Google Play, mobile web, desktop web.
- Comparable task: same food-discovery-to-pre-order-checkout task for each service.
- Scoring: 1–5 (1 = poor/difficult, 3 = acceptable, 5 = excellent); N/A only when not applicable; blank means not tested.
- Evidence: dated URL, screenshot or recording timestamp, and a concise factual observation.
- Safety: stop before order placement or payment; do not expose personal contact, address, or payment details.

## Benchmark framework

The workbook includes 12 criteria across six categories:

1. Discoverability — store/search visibility; value proposition clarity.
2. Access & availability — access reliability; location setup.
3. Menu & item information — restaurant/outlet discovery; item information completeness.
4. Pricing transparency — price clarity; fee transparency.
5. Cart & checkout — cart control; checkout progression.
6. Trust & support — trust information; help and policy clarity.
