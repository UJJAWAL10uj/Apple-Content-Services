# Project 3 — Platform Benchmark & User-Flow Teardown

## Objective
Compare the same food-delivery task across consumer apps and web surfaces in India.

**Proposed competitor set:** Zomato, Swiggy, Domino's, EatSure. This is a proposed audit scope, not a claim that all offer identical features on every surface. Verify access as you audit.

## Platforms
iOS App Store, Google Play, mobile web, desktop web (where available).

## User task
Set a delivery location, discover a restaurant, inspect a menu item, add it to cart, review the complete fee breakdown, and reach the final checkout step without placing an order.

## Workbook
`Platform_Benchmark_User_Flow_Teardown.xlsx` includes Platform Audit, Flow Steps, Friction Log, UX Scorecard, and a formula-driven Summary.

## Method
1. Use the same city/pincode, test task, device conditions, and audit window wherever possible.
2. Record store listing values as displayed on the audit date; they change over time.
3. Capture each journey step, time, user input, system response, backtracking, and friction.
4. Score discoverability, search, menu clarity, cart transparency, checkout clarity, feedback/error recovery, and accessibility.
5. Every score must have a rationale and evidence reference. Leave blank or mark N/A rather than guessing.
6. Synthesize three high-impact friction points and product recommendations.

## Integrity
The workbook contains no invented ratings, review counts, feature claims, or UX observations. Base findings on dated evidence. Redact personal information in screenshots.

## Final deliverable
Executive summary, platform comparison, annotated journey screenshots, friction prioritization, and three product recommendations with measurable success metrics. Add quantified resume outcomes only after the audit is complete and evidence supports them.
